# Venturo AI Profile System


## Overview

Profile System 是 Venturo AI 用户画像核心模块。


用于支持：

 AI Matching
 AI Recommendation
 Investor Discovery
 Expert Matching
 Pitch Participation



---

# User Profile


统一基础模型：


UserProfile


包含：

 用户身份
 行业
 技能
 标签
 描述



---

# Founder Profile


创业者画像：


核心字段：

 创业项目
 当前阶段
 融资需求
 资源需求



用于匹配：

 投资人
 专家
 企业资源
